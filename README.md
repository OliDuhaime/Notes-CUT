# Notes-CUT

Les notes de cours du CUT informatique de l'ÉTS

## Description

Ce projet contient les notes de cours du Certificat en Technologies de l'Information (CUT) de l'ÉTS, mises en open source pour être accessibles à tous. Il vise à centraliser et organiser les notes de cours pour faciliter leur consultation et leur réutilisation.

## Fonctionnalités

- **Organisation des notes** : Les notes sont classées par cours et par séance dans des dossiers appropriés.
- **Utilisation du template** : Un fichier `template-notes-cours-obsidian.md` est fourni pour créer rapidement de nouvelles notes.
- **Gestion des fichiers PDF** : Les fichiers PDF des cours doivent être nommés selon le format `XXX123-01.pdf`, où :
  - `XXX123` correspond au code du cours.
  - `01` correspond au numéro de la séance.

## Structure du projet

- **Dossiers par cours** : Chaque cours dispose de son propre dossier.
- **Fichiers PDF** : Les fichiers PDF des cours sont placés dans les dossiers correspondants.
- **Notes Markdown** : Les notes sont rédigées en Markdown en utilisant le template fourni.

## Utilisation

1. **Créer une nouvelle note** :
   - Utilisez le fichier `template-notes-cours-obsidian.md` pour rédiger vos notes.
   - Suivez le format de nommage pour les fichiers PDF et placez-les dans le dossier du cours correspondant.

2. **Contribuer** :
   - Clonez le dépôt GitHub.
   - Ajoutez ou modifiez des notes en respectant la structure du projet.
   - Soumettez vos modifications via une pull request.

## Contribution

Les contributions sont les bienvenues ! Si vous souhaitez ajouter ou améliorer des notes, suivez les instructions dans la section **Utilisation**.
