### Types de mémoire
**Mémoire vive** ( **RAM** - Random Access Memory) : elle est utilisée par le processeur qui y place les données le temps de leur traitement.
- Rapidité d’accès.
- Mémoire volatile.
Les données sont perdues lorsque l’ordinateur est éteint : mémoire volatile. 
La RAM est classée en 2 types :
- **SRAM** (Static Random Access Memory )
- **DRAM** (Dynamic Random Access Memory )
	- **SDRAM** (Synchronous Dynamic RAM) : Utilisée comme mémoire principale et vidéo. Tend à être remplacée par la DDR SDRAM. On distingue la SDRAM 66, 100 et 133 (fréquence d’accès en MHz).
	- **VRAM** (Video RAM) : Présente dans les cartes graphiques. Sert à construire l’image vidéo qui sera envoyée à l’écran d’ordinateur.
	- **DDR SDRAM** (double la largeur de la bande passante, transfert de données deux fois plus vite que SDRAM), DDR2 SDRAM (DDR2-400, DDR2-533, le nombre représente la vitesse de fonctionnement), **DDR3,4,5 SDRAM** , etc.

**Mémoire morte** (**ROM** - Read Only Memory ) : permet de conserver les données nécessaires au démarrage de l’ordinateur.
- Lecture seulement.
- Non volatile.

**Mémoire de masse** ([[Disque dur]]) : c’est là que seront stockées toutes les informations (programmes, documents, images, photos ... ).
- Accès lent.
- Non volatile et grande capacité
